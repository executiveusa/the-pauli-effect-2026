# The Pauli Effect

Static Next.js launch page for The Pauli Effect.

## What ships

- Pauli-led hero using the provided mascot art.
- P.A.S.S. page order: problem, amplification, solution, system.
- Five-question survey funnel with no browser storage.
- Yappyverse gallery stubs with Pauli as the first public character.
- Ownership, NWKids proof framing, FAQ, Insider Club, blog teaser, and footer.

## Commands

```bash
npm install
npm test
npm run lint
npm run build
```

The local machine showed disk pressure during install, so cloud/CI build proof is the next useful verification step.
